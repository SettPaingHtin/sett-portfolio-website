# Sett Paing Htin — Developer Portfolio

A responsive dark-themed React + TypeScript portfolio built with Vite.

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Before publishing

1. In `src/App.tsx`, replace `your.email@example.com` with your real email.
2. Replace the GitHub and LinkedIn placeholder URLs in the footer with your actual profiles.
3. Confirm the AI Reliability Lab and TaskForge descriptions match what you have actually implemented. They are marked as in progress by default.
4. Add repository links or demos only when you have public, working links.
5. Review all content and contact details before deploying.

## Deploy

You can deploy the Vite app to Vercel, Netlify, or GitHub Pages. For Vercel or Netlify, connect the repository and use `npm run build` as the build command with `dist` as the output directory.
